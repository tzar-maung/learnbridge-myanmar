Before a group lesson

Safe facilitation guide

Use nicknames only, keep activities calm, and let children pass if they do not want to answer. This prototype should support learning without creating private records about children or families.

Collect

  • Nickname
  • Language choice
  • Lesson progress on this device

Do not collect

  • Real names or ID documents
  • Exact location or family details
  • Political or conflict-related information

Run the session

  • Read the teacher note first
  • Practice together before individual answers
  • Reset progress before a new group uses the device

Offline setup

Before internet goes away

Open LearnBridge once while the device has internet or local network access. Then test the cached app before using it with a group.

  1. Start the local server on the teacher computer.
  2. Open LearnBridge in the browser and wait for lessons to load.
  3. Open one lesson, go back, and mark one lesson complete.
  4. Turn off internet or Wi-Fi and refresh the page.
  5. If the app still opens, it is ready for offline practice on this device.

Teacher resource links may need internet. To use outside resources offline, download them first in tools like Kiwix Reader, Kiwix Server, or Kolibri before the session.
