Offline setup

Before internet goes away

Prepare the browser app and external files while online. Then test everything once before using it with a learning group.

  1. Start the local server on the teacher computer.
  2. Open LearnBridge in the browser and wait for activities to load.
  3. Download textbooks, PDFs, Kiwix ZIM files, or Kolibri content separately.
  4. Open one saved file in Teaching Desk to confirm it displays.
  5. Turn off internet or Wi-Fi and refresh the page to test offline access.

External links need internet. Download outside materials first, then use Teaching Desk to open the saved files during class.
